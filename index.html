Maximum yield takes the ceiling off and works up until the site stops supporting another lot. Intended for workshopping a larger site with a planner — expect more options, and a longer run.
Separate from prompt 3, which sets the minimum every lot is tested against. This one decides how the surplus is shared on a rear lot, hatchet or tandem layout — useful when the front lot has to keep a particular area.
An access handle is part of the rear lot's title, so the schemes test the rear lot on the balance behind the strip. An access easement is a right over the front lot — the land stays in the front lot's title and counts towards its area, it just cannot be built on.
A services easement keeps the handle running straight to the street, so the adjacent lot keeps its full frontage and area. Cutting it takes the truncation off that lot — on a narrow frontage that is often what makes it non-compliant.
Generates the frontage rather than using the existing street, then lays out lots either side of it. Entered on this form, not drawn — and it is a layout test, not a road design: no vertical geometry, no turning paths, and the reserve width is yours.

Front lots are held at the minimum lot size so the rear lot takes the balance.
